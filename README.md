# csv_splitter
## Input:
### All input variables can be found under main.
* csv_folder: Directory of csv files to split
* split_length: Maximum number of rows per output csv files
## Output:
* output_folder: Directory where the splitted csv files are exported
# parquet_to_csv
## Input:
### All input variables can be found under main.
* parquet_file_path: File path of the parquet file to be converted
* rename_cols: Dictionary to rename the columns of the orignal parquet file
## Output:
Output file will be named as coverted_parquet.csv
